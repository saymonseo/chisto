# Чисто 0.2.1 — контроль пространства в Windows

Карта папок, крупные файлы, дубликаты, анализ AppData и предварительная очистка
кэшей. Интерфейс на русском языке. Анализ файлов выполняется локально.

## Установка

Загрузите установщик из [GitHub Releases](https://github.com/saymonseo/chisto/releases).
Он работает для текущего пользователя, создаёт ярлыки и запись деинсталляции.
Папка по умолчанию — D:\Programs\Chisto, если диск D: существует; её можно изменить.
Ярлык на рабочем столе — отдельная необязательная галочка.

Нужны Windows x64 и .NET Desktop Runtime 10 x64. Установщик проверяет Runtime;
при отсутствии предложит официальную страницу Microsoft. Portable-архив есть
в том же релизе. Программа и установщик пока не имеют цифровой подписи издателя.

## Анализ и прогресс

Выберите диск или папку и нажмите «Сканировать». Сначала программа подсчитывает
файлы: пока общее число неизвестно, показаны «Учёт…», найденное число и время.
После учёта показаны процент анализа, сколько процентов осталось, файлы из
общего числа, папки, прошедшее время и приблизительная оценка оставшегося и
общего времени. Оценка может меняться из-за разной скорости обработки папок.
Первичный подсчёт добавляет проход по каталогам, зато даёт реальный знаменатель.

По карте можно переходить внутрь папок; таблица справа сортируется по размеру.
Кнопка «Выше» возвращает назад. Операцию можно остановить. Предыдущий завершённый
анализ сохраняется, если область не менялась.

Размеры папок — сумма логических размеров доступных файлов, не уникальных
занятых кластеров. Жёсткие ссылки, сжатые и разреженные файлы могут приводить к
отличию от занятого места диска. Вложенные ссылки, облачные и недоступные папки
пропускаются. Программа не повышает права и не скачивает облачные файлы.
Изменения файлов во время обхода могут изменить итог относительно первичного
учёта; проценты относятся к исходному списку работы.

## Крупные файлы и системный резерв

Показываются 1000 крупнейших обычных файлов области, поиск по имени и пути,
копирование пути и выделение в Проводнике через Windows Shell API.

Служебный резерв памяти Windows учитывается в общем объёме диска и отдельном
блоке «Системный резерв» на карте. Его отдельные файлы не предлагаются в списке
крупных файлов или дубликатов и не входят в очистку. Обычные документы с таким
же именем в пользовательских папках остаются видимыми.

## Дубликаты

После анализа выполните поиск дубликатов. Проверяются файлы от 1 МБ: сначала
размер, затем SHA-256 всего содержимого. Жёсткие ссылки на один физический файл
не считаются отдельными копиями. Есть экспорт CSV. Автоматического удаления нет:
откройте выбранную копию в Проводнике и проверьте её назначение самостоятельно.

## AppData

«Проанализировать AppData» показывает приложения и папки Local, Roaming и
LocalLow: общий размер, путь и наличие распознанного кэша. Можно открыть
расположение или подробно разобрать выбранную папку. Общий размер данных
приложения не означает, что всё это можно удалить.

## Очистка приложений

Нажмите «Проверить приложения», изучите список, отметьте категории и подтвердите
конкретный объём. Категории не выбраны автоматически. Распознаются существующие
стандартные каталоги:

- Temp текущего пользователя;
- кэши Chrome, Edge, Brave и Яндекс Браузера;
- Cache, Code Cache и GPUCache VS Code, Discord, Codex Desktop, Claude, Slack,
  Obsidian и Element;
- HTTP-кэш и wheels pip;
- диагностические .dmp/.mdmp в CrashDumps старше 7 дней.

Для обычных кэшей минимальный возраст — 24 часа. Соответствующее приложение
должно быть закрыто. Настройки, чаты, cookies, пароли, IndexedDB, Local Storage,
tdata Telegram, расширения и документы не входят в правила. После очистки кэш
может скачаться повторно; очистка pip не удаляет установленные пакеты.

Удаление **безвозвратное**, минуя Корзину. Перед удалением проверяются правило,
путь, ссылки в родительских папках, размер и время изменения. Удаляется открытый
и проверенный файловый дескриптор. Изменённые, занятые, системные и read-only
файлы пропускаются. При отмене уже удалённые файлы не восстанавливаются.
Программа не очищает реестр, WinSxS или весь AppData.

## Обновления

Раздел «Обновления» вручную проверяет публичные GitHub Releases saymonseo/chisto.
Файлы пользователя и результаты анализа не отправляются. Загружается только
установщик из этого репозитория; проверяются размер и SHA-256 из GitHub API.
Установка требует отдельного согласия. Обычные проверки Windows сохраняются.
При запуске программы сетевых запросов нет.

Источник — update-source.json рядом с EXE. Токенов GitHub в приложении нет.

## Сборка и публикация

Нужны .NET SDK 10 и Inno Setup 6. Запустите build-release.ps1 в PowerShell.
Он собирает EXE, выполняет тесты на искусственных файлах, создаёт установщик,
portable ZIP и SHA256SUMS.txt. Реальные пользовательские кэши тестами не очищаются.
Иконка имеет размеры 16–256 px; генератор — Build-Icon.ps1.

Тег v0.2.0 запускает GitHub Actions. Перед следующей версией обновите Version в
Chisto.csproj. Версия в интерфейсе, обновлениях и установщике берётся из проекта.
Создайте соответствующий тег после проверки. Workflow публикует установщик,
portable и контрольные суммы. Токены в исходниках не хранятся.

## Полезные следующие функции

- История роста папок: что заняло новое место за неделю.
- Разбор Загрузок: старые установщики, образы, архивы и возраст файлов.
- Отдельный отчёт Docker/WSL с действиями через штатные инструменты вместо
  удаления VHDX с данными.
- Исключения, сохранённые области сканирования, сравнение двух анализов.
- Подписанные сборки, восстановление удалённого кэша и проверка установки
  в чистых виртуальных машинах Windows.
